# Percona 笔记

---

## 简介

 [Percona](https://www.percona.com) 是一家专注开源数据库的技术公司，最出名的是它的 [MySQL](MySQL_Note.md) 增强分支和一堆运维工具，圈内常被称为「MySQL 运维全家桶」。它由原 MySQL 运维团队成员在 2006 年创立，核心产品都开源免费，靠商业技术支持服务赚钱。‌‌

### Percona Server  fo MySQL

「Percona Server  fo MySQL」 由 [Percona](https://www.percona.com) 发布。它免费提供了官方企业版才有的功能。
